# Custom-Stock-Composite-Scorer

I built this while doing the Wharton Investment Competition 2025. We had this huge stock universe from various countries and industries and honestly, everyone on my team had a different way of deciding if a stock was good. Also various websites ggives their own view and just raw stats. It was hard to go through all that data and objectively rank stocks. So  I decided to build this and experiment whether it is possible to use python to be able to more easily and accurately screen stocks based on their financials.

It pulls real data from Yahoo Finance for whatever stocks I give it, checks the company across a few different angles — how cheap it is, how good the actual business is, how financially healthy it is, how fast it's growing — and gives out one number out of 10 as a composite score.
